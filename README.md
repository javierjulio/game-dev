# Game Dev Experiments

This is a collection of web game dev experiments. I started with ECSY then switched to [bitECS](https://github.com/NateTheGreatt/bitECS). The circle collision math was from the video https://www.youtube.com/watch?v=XD-7anXSOp0 with the source at https://github.com/adiman9/pureJSCollisions

## Getting Started

1. Use [Node.js v22+](https://nodejs.org/)
2. `npm install`
3. `npm start` (will open in default browser)

## Deploy to GitHub Pages

To build the production bundle and deploy run: `npm run deploy`.
